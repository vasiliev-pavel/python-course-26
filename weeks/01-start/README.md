# Неделя 1. Переменные, ввод и вывод

## Занятие

**Цель:** установить всё нужное, научиться считать в Python и делать коммиты.

### Шаг 1. Установка

Сделай «Начало работы» из [главного README](../../README.md#начало-работы).

### Шаг 2. Ветка команды

Преподаватель скажет номер команды. **Один** из пары создаёт ветку:

```bash
git switch -c team03
git push -u origin team03
```

Второй забирает её себе:

```bash
git fetch
git switch team03
```

### Шаг 3. Шпаргалка

```python
name = "Аня"                  # строка
age = 18                      # целое число (int)
height = 1.65                 # дробное число (float)

age = int(input("Возраст: ")) # input всегда даёт строку, int() делает из неё число

7 / 2    # 3.5  обычное деление
7 // 2   # 3    деление нацело
7 % 2    # 1    остаток

print(f"Привет, {name}! Тебе {age + 1} в следующем году.")
print(f"Рост: {height:.1f}")  # один знак после точки
```

### Шаг 4. Практика

Каждый делает **сам**, на своём компьютере. Скопируй файл практики к себе в команду, вместо `ivanov` — своя фамилия:

```bash
cp weeks/01-start/practice.py teams/team03/practice/01_ivanov.py
```

Реши задачи (вместо `...`), запусти файл: правый клик → **Run**. Все строки должны стать `OK`.

```bash
git add teams/team03/practice/01_ivanov.py
git commit -m "team03: practice 1 ivanov"
git pull --no-rebase --no-edit
git push
```

`git pull` перед `push` нужен, потому что напарник тоже пушит в эту ветку.

## Лаба

**Цель:** первая программа игры — карточка героя.

**Что сдаём:** `teams/teamXX/lab1.py`, все проверки `OK`, Pull Request.

Работаете **вдвоём за одним компьютером**: один печатает (водитель), второй подсказывает и ищет ошибки (штурман). Каждые 15 минут меняетесь.

### Шаг 1. Локация

Выберите тему своей локации (у всех команд разные): лес, пещера, замок, болото, башня мага, кладбище, ледник, пустыня, корабль-призрак, шахта — или своя. Впишите её и участников в `teams/team03/README.md`.

### Шаг 2. Карточка героя

Откройте `teams/team03/lab1.py`. Что сделать, написано в комментариях. Запуск — правый клик → **Run**, ввод — внизу в консоли.

### Шаг 3. Проверка

```bash
python check.py 1 team03
```

### Шаг 4. Коммит и Pull Request

```bash
git add teams/team03
git commit -m "team03: hero card"
git push
```

На GitHub: **Pull requests → New pull request**, base: `main`, compare: `team03`. Название: `team03: лаба 1`.
