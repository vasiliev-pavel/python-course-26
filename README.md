# Подземелье 🗡️

За курс мы вместе пишем текстовую игру. Герой проходит через 10 локаций — **каждую локацию делает одна пара**. Начинаем с `print` и переменных, заканчиваем классами и сборкой всех локаций в одну игру.

Каждую неделю — **занятие** (новая тема и короткая практика, каждый сам) и **лаба** (следующий шаг игры, вдвоём).

## Начало работы

1. Установи [Python 3.12](https://www.python.org/downloads/) (при установке отметь **Add python.exe to PATH**), [PyCharm Community](https://www.jetbrains.com/pycharm/download/) и [Git](https://git-scm.com/downloads).
2. Представься git'у (имя латиницей и почта, как на GitHub):

```bash
git config --global user.name "Ivan Ivanov"
git config --global user.email "ivan@example.com"
```

3. Склонируй репозиторий и открой папку `python-course-26` в PyCharm (File → Open):

```bash
git clone https://github.com/vasiliev-pavel/python-course-26.git
```

## Команды

| Папка | Ветка |
|---|---|
| `teams/team01` ... `teams/team10` | `team01` ... `team10` |

Номер команды скажет преподаватель. Пара работает **только в своей папке** и своей ветке.

## Перед каждым занятием

```bash
git switch main
git pull
git switch team03
git pull
git merge --no-edit main
```

`team03` — твоя команда. После этого у тебя есть новое задание (`weeks/`) и все изменения напарника.

## Проверка

Команды набирай в терминале PyCharm (вкладка **Terminal** внизу):

```bash
python check.py 1 team03
```

`1` — номер лабы, `team03` — твоя команда. `OK` — всё верно, `FAIL` — видно, что ожидалось и что получилось.

## Правила

- Меняем **только свою папку** `teams/teamXX`. Файлы `check.py`, `checks/`, `game/` не трогаем.
- Коммит — после каждого законченного шага, сообщение по делу: `team03: hero card`.
- Из ветки команды должен быть открыт Pull Request в `main`. Если старый влит — открываем новый.

## Если нет интернета

Всё, кроме `pull` и `push`, работает без интернета: пиши код, запускай проверки, делай коммиты. `git push` — когда интернет появится. Новое задание забери у преподавателя (флешка) или у одногруппника.
